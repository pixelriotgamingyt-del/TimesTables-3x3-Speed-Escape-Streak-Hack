TimesTables 3x3 Speed Escape Streak Hack

A **Tampermonkey userscript** for TimesTables 3x3 Speed Escape, focused on keeping your streak going and helping you chase higher scores.

## Requirements

- A browser with [Tampermonkey](https://www.tampermonkey.net/) installed.
- The userscript code from this repository.
- Access to TimesTables 3x3 Speed Escape.

## Installation

1. Install Tampermonkey for your browser.
2. Open the userscript file in this repository and copy its entire contents, including the metadata header.
3. Open the Tampermonkey dashboard and select **Add a new script**.
4. Replace the default template with the copied code.
5. Save the script and make sure it is enabled.
6. Open TimesTables 3x3 Speed Escape, or refresh the game page if it is already open.

For more installation options, see the [official Tampermonkey installation guide](https://www.tampermonkey.net/faq.php?locale=en&q=Q102).

## Usage

Keep the userscript enabled while using the game. To disable it, turn it off in the Tampermonkey dashboard and reload the game page.

## Troubleshooting

If the script does not load:

- Check that Tampermonkey and the userscript are both enabled.
- Make sure you copied the complete script, including its metadata header.
- Check that the game URL matches the script's `@match` or `@include` rules. See [Tampermonkey's matching documentation](https://www.tampermonkey.net/documentation.php?locale=en&q=include).
- Check Tampermonkey's site permissions, then reload the page.
